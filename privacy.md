# Privacy policy

SmartPick Guide is a static website. We do not ask you to create an account, and we do not collect names, email addresses, or payment details.

**Hosting.** This site is hosted on GitHub Pages. GitHub may log technical information such as IP addresses for security and operations; see GitHub's privacy statement.

**Affiliate links.** When you click a link to Amazon, Amazon may set cookies to attribute a purchase to this site. That data is handled by Amazon under its own privacy notice; we only see aggregated sales reports and never your personal or order details.

**Changes.** If this policy changes, the updated version will be posted on this page.
